# Websites World 🌐

> A clean, responsive single-page web dashboard to store, organize, and quickly access all your essential bookmarks, tools, and developer resources in one place.

## 📖 Overview

**Websites World** (Website Organizer) is a lightweight, customizable desktop & mobile web app that replaces cluttered browser bookmarks. It features category grouping, search with fallback options, recent activity tracking, quick unsaved site saving, cloud preset sync, custom background themes, and full data export/import capabilities.

---

## ✨ Key Features

* **Categorized Dashboard:** Group links into custom categories (e.g., A.I, Work, Coding, Typing).
* **Instant Search & History:** Quick filter across all saved links, search history dropdown, and web fallback buttons (Google & Edge/Bing).
* **Smart Sorting & Recents:** Frequently opened links float to the top; tracks your 3 most recently opened sites.
* **Unsaved Site Quick-Save:** Floating notification banner to quickly categorize newly visited sites.
* **Appearance Customization:** 10 curated color themes, high-res background wallpapers, or upload your own custom wallpaper image.
* **☁️ Sync & Share Presets:** Share your link setups across devices or load community/preset configurations using portable share tokens.
* **Data Privacy & Portability:** All data is stored locally (`localStorage`). Includes 1-click **Export** and **Import** (JSON).
* **Edit & Drag-and-Drop:** Intuitive edit mode with double-click renaming, drag-and-drop link/category reordering, and undo notifications.

---

## 🛠️ Tech Stack

* **HTML5** – Semantic markup
* **CSS3** – Custom CSS variables, flexbox, CSS grid, glassmorphism UI, and smooth animations
* **JavaScript (ES6+)** – Vanilla JS (DOM manipulation, LocalStorage API, Clipboard API, and FileReader API)
* **Zero External Dependencies** – No frameworks required, runs directly in any modern browser

## 🚀 Getting Started

### Prerequisites

All you need is a modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari).

### Installation & Running

1. **Clone the repository:**
   ```bash
   git clone https://github.com/venkatpavankumar087/Website-Organizer.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd Website-Organizer
   ```

3. **Open the application:**
   * Double-click `index.html` to open it directly in your browser, **OR**
   * Use a local dev server (e.g., Live Server extension in VS Code):
     ```bash
     npx live-server .
     ```

## 💡 Usage Guide

| Action | Shortcut / Method |
| :--- | :--- |
| **Focus Search Bar** | Press `Ctrl + F` or `Cmd + F` |
| **Close Dialogs / Exit Edit Mode** | Press `Esc` |
| **Edit Mode** | Click the `+` button top right $\rightarrow$ select `✏ Edit category` |
| **Rename Category / Link** | Double-click on any category title or link while in Edit Mode |
| **Customize Appearance** | Click the floating pencil icon in the bottom-right corner |
| **View Link Details & Notes** | Right-click any link in normal mode |
